01_CORE_PHILOSOPHY

RawCore.AI is designed for unfiltered interaction. There are ZERO hidden system prompts or pre-configurations. The AI responds exactly as the model architecture dictates based on your input. No filters, no guardrails beyond the model's native training.

02_MODELS_AND_FAILOVER

  • TEXT_MODELS: Primary models for chat and reasoning. Select your preferred provider (Gemini/Groq) via the top dropdown.
  • VOICE_MODELS: Dedicated Speech-to-Text models (Whisper/Gemini) used when recording audio.
  • FAILOVER_LOGIC: If an API key encounters a Rate Limit (429) or Server Error (5xx), the system automatically cycles to the next key in the administrator's pool. This ensures maximum uptime without user intervention.

03_FILE_ATTACHMENTS

  • MULTI_MODAL: Upload images for visual analysis (requires vision-capable models like Gemini-1.5).
  • CONTEXT_FEEDING: Non-image files are attached as metadata/context to help the AI understand specific project files or documents.
  • METHODS: Use the paperclip icon, drag-and-drop directly into the chat window, or paste images from your clipboard (Ctrl+V).

04_HISTORY_MANAGEMENT

  • AUTOSAVE: Every conversation is synced to your account. Titles are intelligently generated based on the first few exchanges.
  • MANAGE_MODE: Click "MANAGE" in the sidebar to enter batch selection mode. Select multiple chats for bulk deletion.
  • CUSTOM_TITLES: Use the pencil (✎) icon in the sidebar to manually rename any conversation.

05_EXPORT_PORTABILITY

  • WHOLE_CHAT: Export to Markdown (.md), Plain Text (.txt), or PDF via the sidebar menu.
  • INDIVIDUAL_MESSAGES: Use "COPY_RAW" to get the unformatted text or "EXPORT_PDF" for a single-message document.
  • CODE_SNIPPETS: Every code block features an instant copy button for developer workflows.
